# NicheMaster Ebook Agent

Python tooling for turning a niche/product definition into a finished ebook package.

Planned pipeline:

1. Load niche and product metadata.
2. Build or validate the outline.
3. Generate chapter content.
4. Render EPUB/PDF output.
5. Generate or attach cover art.
6. Emit a storefront-ready product manifest.

Keep provider credentials in environment variables or a local `.env` file that is ignored by Git.
